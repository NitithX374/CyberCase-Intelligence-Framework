- **ระดับความเสี่ยง**: 🟡 **MEDIUM** (Ambiguous)
- **รูปแบบข้อความที่พบขัดแย้งกัน**:
  - หน้า 3 บรรทัดที่ 88: `การสอบสวนผู้กล่าวหา มีจำนวน ๒ ปาก คือ` (สอบนายถนอม และ น.ส.พัชร์สิตา)
  - หน้า 3 บรรทัดที่ 98: `การสอบสวนผู้กล่าวหา \n ไม่มี`
- **กลไกและสาเหตุ**:
  - ตามโครงสร้างรายงานการสอบสวน หัวข้อถัดมาต้องเป็น `การสอบสวนผู้ต้องหา` แต่แบบพิมพ์ของ สน. พิมพ์หัวข้อซ้ำเป็น `การสอบสวนผู้กล่าวหา` อีกครั้ง โดยระบุว่า `ไม่มี` เนื่องจากผู้ต้องหาหลบหนี
  - จุดนี้ไม่ใช่ OCR error แต่เป็น Source Document Typo ที่ระบบ AI ถ้าอ่านแบบตรงไปตรงมาจะเกิด Logic Contradiction ทันที (เพิ่งบอกว่าสอบผู้กล่าวหา 2 ปาก แต่บรรทัดถัดมาบอกสอบผู้กล่าวหา: ไม่มี)

## 3. สรุปความเที่ยงตรงของข้อมูลจำนวนเงินและค่าเสียหาย (Financial Accuracy Check)

จากการตรวจสอบข้ามส่วน (Cross-sectional Validation) ในเอกสารฉบับนี้:
- **ราคาทรัพย์ที่ถูกประทุษร้าย (หน้า 2)**: `๕๒,๐๐๐ บาท`
- **สรุปข้อเท็จจริง (หน้า 3)**: รวมมอบเงินให้ไป `๕๒,๐๐๐ บาท`
- **คำให้การผู้กล่าวหาที่ ๑ (นายถนอม)**: มอบเงินสด `๒๕,๐๐๐ บาท` (ค่าจองแผง), ค่าเช่าเดือนละ `๒,๐๐๐ บาท`
- **คำให้การผู้กล่าวหาที่ ๒ (น.ส.พัชร์สิตา)**: มอบเงินสด `๒๗,๐๐๐ บาท` (ค่าจองแผง 25,000 + ค่าเช่าล่วงหน้า 2,000), ค่าเช่าเดือนละ `๒,๐๐๐ บาท`
- **การรวมยอดเงิน**: $25,000 + 27,000 = 52,000$ บาท **ถูกต้องและสอดคล้องกันสมบูรณ์ทุกหน้า** (ไม่มี Numeric Drift ในส่วนตัวเลขเงิน)

## 4. ข้อสังเกตเชิงโครงสร้างสำหรับการนำไปใช้ใน Agentic RAG

1. **อันตรายของ Extractive Grounding ต่อลายมือเขียน (Handwriting Trap)**:
   - หากระบบ RAG ตอบคำถามโดยยึดข้อความ OCR หน้า 5 จะตอบว่า *"ศาลฎีกาเป็นผู้ออกหมายจับผู้ต้องหา"* ซึ่งเป็นการให้ข้อมูลเท็จ (Hallucination ที่รับมาจาก OCR) ทั้งที่ความเป็นจริงคดีนี้อยู่ในอำนาจศาลแขวงพระนครเหนือ
2. **การอ้างอิงเลขหมายจับ (Warrant Drift Trap)**:
   - ระบบ RAG ต้องมีกลไกไกล่เกลี่ยระหว่าง `๑๕๒/๒๕๖๓` (หน้า 1) และ `๑๕๒/๒๕๖๒` (หน้า 2, 4) มิฉะนั้นการทำ Automated Verification กับฐานข้อมูลศาลจะล้มเหลว
3. **ความจำเป็นของ Layer Entity Reconciliation ก่อนเข้าสู่ Context Builder**:
   - การทำ OCR Consistency Audit เช่นนี้ เป็นด่านคัดกรองที่จำเป็นอย่างยิ่งสำหรับเอกสารคดีความและสำนวนการสอบสวน ก่อนส่งข้อความเข้ากระบวนการวิเคราะห์หรือทำ Case Summary รายงานต่ออัยการ
